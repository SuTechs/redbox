# Red Box 1.1.0 (3) release

Prepared and submitted 31 October 2026. Package/bundle ID: `com.sutechs.redbox`.
Release source begins at `6a357d6`, including the custom Zen mode logo, with a
release-QA compact-mascot fix added before the final build.

## Plan

1. Verify the live store versions and reserve version 1.1.0 (final build 3).
2. Run formatting, analysis and the full Flutter suite. Build a signed Android
   App Bundle and a signed iOS archive; export the App Store IPA.
3. Refresh both descriptions, release notes and six marketing screenshots for
   Android, iPhone and iPad, using current native Flutter captures.
4. Upload the final build 3 to Play Console and App Store Connect. Attach the processed
   builds to the production release/version and reuse the existing tester groups.
5. Send the production update and iOS version for review, preserving existing
   privacy declarations, availability, ratings and automatic release preferences.
6. Record the final console states and screenshot evidence. Keep credentials,
   signing files and account-specific upload logs in ignored `release-private/`.

## Release content

- A growing Normal memory challenge, with larger boards, more reds and gradual
  visible shuffles. Preview time follows the amount to remember.
- Level-free Zen mode with random, beautiful shaped boards, one or two reds,
  Another board and gentle retries. A custom sage-and-coral Zen logo.
- Clearer Home navigation, a simple Normal-only level browser, fitted dense
  layouts and rotation support. Existing Normal progress and comfort options stay.
- Original relaxing music, offline play, no ads, accounts, purchases or tracking.
