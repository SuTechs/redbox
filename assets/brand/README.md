# Red Box logo

Created with the built-in imagegen tool for this project. The final app icon is `logo.png`; `logo-source.png` preserves the generated original. The platform exports are produced by `tools/export_brand.py`.

## Generation prompt

Use case: logo-brand. Asset type: production app icon for Red Box, a soothing Flutter memory game, Android/iOS/web. Create a single square 1024x1024 full-bleed icon. Background warm flat cream #FFF8ED, opaque and extending to all canvas edges without an outer rounded-square mask. Center one charming coral red square pocket-toy character, with very gently rounded corners, a subtle darker coral bottom edge giving tactile depth, and just two small dark warm-brown oval eyes plus a tiny calm curved smile. The square fills about 58% of the canvas and has a playful very slight counterclockwise tilt. Refined simple 2D vector-like illustration, softly tactile, restrained shadow, clean solid shapes, calm and friendly, recognisable at 32px. Palette coral #ED6258, dark coral #CB4A42, cream #FFF8ED, brown #642E28. No text, no letters, no border, no extra objects, no glow, no texture, no photographic rendering, no watermark. This mascot matches our approved Pocket toy design.
