# Original Red Box music

Cloud drift and Warm keys are original instrumental compositions synthesized specifically for Red Box by `tools/generate_music.py`. They use no recordings, samples, downloaded music, or third-party compositions. Both are 64-second periodic WAV loops, 22,050 Hz mono PCM16, with ample headroom. Playback is quieter than tap effects and fades in and out.

Cloud drift uses slowly overlapping Cmaj7, Am7, Fmaj7, and Gsus2 pads. Warm keys adds sparse soft notes with quiet reflections. All audio assets are bundled for offline play.
